## History material and prose — concept before implementation

Purpose: understand what the agent did without decoding the harness's markup. Lead with file identity or the agent's own command description, then outcome and material. A recorded file citation is a file reference: use its basename, optional recorded line/range and the existing lexical inside-workspace navigation. Full path belongs in the tooltip; outside or unsupported references remain inert, readable references. Never execute a link, read a path or interpret HTML from prose. Fenced and inline code remain literal, including directive examples. Unknown/malformed directives stay literal rather than silently disappearing. Very long/non-Latin names wrap within the reading measure. No new persistent badge, box or looping motion. Image-view/generated-image cards similarly lead with the filename; preserve the complete original reference in arguments and image reading. Changing a title does not change image-byte availability.

Native case inventory before changes: genuine Codex `58787f2c` has five prose owners containing file-citation directives (attributes path and purpose) and 45 image operations. Claude's selected genuine journal has no such directive; its ordinary Markdown is the regression case.

## Workspace/file family — detailed decisions before edits

Opening a named file before consent must keep that filename visible; consent is an explicit prerequisite, not an anonymous empty Workspace. The layout menu is called Layout and the active file menu File, so their scope is visible as well as accessible. A Markdown file past the rendered-document limit opens directly as Source with one factual note; its text is available and is not an error or an apology requiring another click. Document stays disabled with its reason until the existing limit permits it. Draft editing, current-source conflicts, split panes, keyboard tab behavior and native submission are unchanged.

The recorded-file reader keeps Workspace and Compare steps as its primary actions; reading today's disk file moves into its existing File actions menu. Compare with disk remains beside the exact recorded version it acts on. The step selector names the action/time/version, not the filename already in the header and trail. Source, comparison, trail and overflow states must still be reachable by keyboard. No source geometry or scroll-anchor ownership changes.
