## History material and prose — concept before implementation

Purpose: understand what the agent did without decoding the harness's markup. Lead with file identity or the agent's own command description, then outcome and material. A recorded file citation is a file reference: use its basename, optional recorded line/range and the existing lexical inside-workspace navigation. Full path belongs in the tooltip; outside or unsupported references remain inert, readable references. Never execute a link, read a path or interpret HTML from prose. Fenced and inline code remain literal, including directive examples. Unknown/malformed directives stay literal rather than silently disappearing. Very long/non-Latin names wrap within the reading measure. No new persistent badge, box or looping motion. Image-view/generated-image cards similarly lead with the filename; preserve the complete original reference in arguments and image reading. Changing a title does not change image-byte availability.
