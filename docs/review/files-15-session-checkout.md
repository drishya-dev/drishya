## Causes and boundaries

The old root list included every recorded cwd. A multi-root projection also had no single `workspaceRoot`, so the map fell back to all recorded paths rather than indexing the selected session's own checkout. A continued session could additionally choose its oldest parent's checkout. The new graph guard uses the selected recording's captured root, rejects an unrelated saved graph root, and keeps explicit combined exports captured-only. Raw root aliases remain available for exact path and consent proofs.

The real Codex acceptance found a separate reading gap: a shell read had captured stdout associated with a read path, but FileHistory offered no material because it was not a typed Read snapshot. The approved addition exposes that output as **Captured command output**, including the warning that it can contain anything the command printed. A full output artifact wins over its preview. It is never offered as a source snapshot or a source comparison; pending, empty and merely mentioned paths do not acquire invented material.

Other roots' existence is refreshed when the group is reopened, including while the journal is idle. A missing directory says Removed; an inaccessible or nonlocal path says Disk unavailable. This grants no current bytes. Root rows use the existing fixed-height tree and tokens, with a second compact metadata line; a detached HEAD uses its folder name while retaining the recorded ref in its description. No new layout, motion or design system.
