# Captured resources and document handoffs

18 October2026. Bounded addition to the adaptive-content work; TASKS remains the sole checklist.

| Before | After | Why |
| --- | --- | --- |
| Structured resource references buried in tool JSON | One explicit inspector with filter and keyboard reference list | Inspect result material without adding a permanent panel |
| Reference URL and captured text hard to distinguish | Reference/body labels, source field, literal copy and explicit current-URL opening | A current URL is not proof of captured document bytes |
| Embedded Markdown/JSON/CSV remains raw | Opt-in Document/Source and existing bounded data readers | Reuse familiar reading controls without inferring a schema |
| Child dialog Escape also closes its resource parent | Cancel propagation stops at its owning dialog; child focus returns | Keep reading context and avoid cascading exits |

Pure extraction supports sealed resource/resource_link blocks, result URL metadata and known native/fulfilled JSON envelopes. Supplied payload must be complete JSON within256KiB; traversal caps64references,1024visits and eight nested levels. Overflow is explicit and original result access remains. No arbitrary string/code/HTML/prose scraping or exact command dispatch. Mixed siblings remain in the original tool result. Open resource strings are ephemeral snapshots, not saved session metadata.

URI navigation is clean absolute HTTP(S) only, with no credentials/control characters/backslashes. External navigation requires a click and opens a separate tab without referrer/opener. File/resource/unsupported schemes are copyable references only. No fetch, remote thumbnail, local-path resolution, HTML/SVG execution or reconstruction of missing media. Captured Markdown uses the established safe renderer; source remains exact. Image/PDF transport/privacy and complete-artifact recovery remain separate.

**Motion verdict:** Existing shared occasional modal arrival/exit is retained (200ms/140ms transform/opacity); keyboard/reduced-motion exits remain immediate. Reference and view switching is immediate: content is mounted whole, never typed or delayed. No new looping or layout animation.

**Validation:**Both TypeScript projects/build;540unit tests/97files. Seven resource/structured-data browser journeys pass, with a final native/MCP resource rerun after unique panel IDs and focus assertions. Covers nested Escape and close-button ownership, clipboard equality, unsupported URIs, explicit link opening, no automatic remote loads, safe Markdown and1440/390/320px. Three actual Drishya/Skeletongraph Codex/Claude long-history/multi-file Workspace regressions pass. Resource-specific protocols are synthetic fixtures, not a claim that every real-session result contains these fields. Private frames inspected under.local. No hosted CI or native turn.
