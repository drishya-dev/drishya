## Motion and interaction

Captured characters arrive whole at final reading size. A separate finite surface outline unfolds from the measured instrument boundary to the content boundary. A Read additionally connects its actual file marker; tool emission and file location are separate relationships. Hover exposes an evidence-backed location/instrument link. Nothing implies that an adjacent operation caused another. Wheel, pointer reading, keyboard navigation, theme/view changes, resize and motion-off cancel active transitions and pending arrival frames. Reduced-motion preference disables animated flights. No loops, fake scans, typing, token streaming or fabricated private reasoning.

Reading inspection preserves focus on close and explicitly distinguishes an earlier captured read from immediate-before bytes and derived-after reconstruction. Native tools and MCP names remain reachable through a narrow-screen drawer. The footer's full-passage reveal is a synthetic design sampler, **not a live stream, event-boundary replay or final transport design**.

## Scope and next implementation

This does not replace or certify the integrated React reader. The fixture renderer eagerly reads a small committed synthetic bundle; it is unsuitable for large-session production. No backend, schema, harness files, real imports, dependencies, telemetry or control capabilities change.

Next integrated slice: retain the worker/paged data source and pure as-of composer; carry approved material surfaces into existing operation renderers; derive agent crown from the displayed evidence cutoff; keep source and actual tool origins separate; let captured input appear immediately and late output resolve in the same stable object. Continue accumulating history while reading is held. Per-view switches need semantic anchors and the same replay cutoff, not just scroll offsets. Do not let cinematic presentation delay capture or fabricate progressive output. Performance, ten-minute calmness and human comprehension still require their own acceptance.

Browser validation covers captured deep reading/provenance/focus, file filtering, theme/view preservation, adaptive roster, interrupted arrivals, contrast tokens and narrow tool access. These are technical checks, not evidence that the design is preferred or market-leading. Physical B4 release checks remain open.
