## The new composition

- **Session library:** actual workspace navigation and session surfaces. Harness, title, workspace and recorded time are visible before opening. Search/filter work against all loaded metadata; rendering starts at 30 sessions and explicitly reveals more. Connection discovery is separate from native execution consent. No fake demo counts or fabricated summaries.
- **Work canvas:** open dot field with a quiet bounded sample of actual repository topology. Action groups sit in the middle; prose stays outside material surfaces. Opening the floating explorer does not squeeze or move the canvas. Files, repository and Git are compact canvas destinations; the session identity stays visible. The right toolbox contains observed native kinds, MCP drawers and actual agent identities.
- **Material language:** common charcoal outer material, inset evidence, soft one-pixel contour, small semantic icon/port accents and thin error treatment. Read uses a range header and source; edits use hunk coordinates and actual patch lines; search shows query and real matches; shell pairs command with result; MCP/other show captured input and result; tests show derived aggregate counts and a bounded count visualization. Preview limits are disclosed and complete stored material remains reachable in the reader. A count tile is not an identified test or an assertion about execution order.
- **Connections:** measured curves connect captured action order. They are not causal edges or a visualization of private model reasoning. Repository links are only recorded static imports; spatial aggregation does not claim architectural communities. A disclosed node/edge cap keeps dense maps bounded.
- **Reading:** the inspector is an intentional reading surface with current/captured provenance, syntax, range/find controls, related operations and local review questions. Current source/Git keep separate permission and content freshness. Git's horizontal/vertical source scroll remains inside its bounded reader. The toolbox yields its space to inspection.
- **Continue:** a compact composer with attachments, pasted images, folder input, explicit native connection details, available model/effort, exact one-time approvals and interrupt. Native policy is reported, not weakened. Keyboard/pointer submit use the same eligibility predicate. The initial state says Checking connection rather than falsely declaring unavailability. Rootless historical sessions stay readable and explicitly cannot be resumed.
- **Environment:** Settings → UI versions offers Legacy and Modern, preserving the session hash and query on switch. Search, settings, consent, errors and library share the same typography and surface scale. Legacy remains independently loaded with its original CSS.

The Modern implementation has its own library, tree, toolbox, action content, prose, connection geometry, repository map and layout in `apps/ui/src/modern`. It reuses the independent draft's authenticated transport, native controller bindings and evidence/Git readers in `fresh`, not Classic rendering or Classic CSS. Internal `fr-*` names identify those retained components, not a selectable Workbench product.

## Motion decisions and skill review

Installed skills used: `emil-design-eng` and `animate`. Text is mounted whole and selectable. There is no typing simulation or invented scanning. A card arrives as one actual DOM material from a visible matching file/tool origin; an absent origin is not invented. Tool kind disambiguates shared harness tool names such as `exec`. Finite camera following reacts to late material height; deliberate upward/keyboard history reading detaches the camera. Replay advances independently.

| Before | After | Why |

| Dense map shows every file name at once | Screen-space density groups, white points, actual aggregated imports, deliberate zoom/search and focused labels | Keep topology navigable rather than a wall of overlapping text |

## Map boundaries

The current Modern map is **2D**, with spatial aggregation rather than folder hierarchy. Coordinates are deterministic; coincident points are separated deterministically for close reading. It considers at most 5,000 nodes and draws at most 1,200 aggregated visible links. Counts and culling limits are disclosed. The background samples at most 180 actual files/240 imports. Search targets actual indexed paths. This does not replace the older 3D camera's parity requirement; do not describe this map as 3D or claim measured large-repository performance from its bounds alone.
