## Mechanics and scope

`useHoverReading` lifts the same article into a manual native popover; a same-size resting slot keeps neighbouring history stable. A 280 ms dwell avoids incidental passes, followed by a 780 ms measured whole-material transfer. The latest feedback replaces automatic centring with source-near positioning clamped to history bounds and clear of header/composer; reading stays scrollable inside the enlarged material. Return uses the visible rectangle and the current slot; interruption/revival reads the current rectangle before cancellation. The builder rejected width/height-only hover because text reflow preceded the boundary, so retain whole-card zoom. History reflow excludes focused popovers. Moving the pointer alone preserves live follow; selecting/copying preserves the material, Escape restores, deliberate scrolling/navigation cancels. No copied evidence, typed characters or synthetic observations. Desktop hover is enabled by default and has a Settings toggle; narrow/touch, low-resource and unavailable popover browsers retain explicit Expand instead. Reduced-motion focus is immediate.

Arrival reserves the current measured allocation while the same real DOM travels from its origin. Results are mounted immediately inside its scrollable body; after the flight and 280 ms settlement, actual width/height allocation grows over 780 ms. Navigation, pointer reading, scrolling, motion/resource changes and cancellation remove the hold. This is a finite presentation delay, not delayed capture, delayed artifact availability or fabricated output. Reflow and connection endpoints continue to measure real DOM. Visible relationship paths remeasure during finite hover/growth and on scroll, instead of using an expired initial animation deadline.

Test tiles remain bounded to 80 per status for summary-only counts, explicitly reporting additional outcomes. They are grouped counts, never runner indices. Complete flat TAP output with contiguous unique indices and exactly matching summary counts may show its actual numbered outcomes (bounded to 240); partial, nested, duplicate or inconsistent output falls back to grouped counts. Existing summary schema is unchanged. This is frontend derivation from captured text, not captured metadata.

Map details preserve the cached spatial pyramid and true import aggregation. Background edges are sampled deterministically with a 120-to-600 paint budget as zoom increases; hover emphasizes incident edges of the visible file/group. Labels/dots crossfade rather than relocating root files or introducing folder-only hierarchy. Modeless map readers sit to the right of usable graph space; other readers stay modal. Current disk needs selected-workspace consent and remains distinct from historical source.

Full-height work passes behind progressive header/composer edge masks. The composer field remains transparent; only its bounded backdrop veil softens the underlying work. Low-resource mode removes blur. Prose/prompt/native receipt text is 15 px; code/diff comparison stays 12 px mono. Verification is concise but still labels recorded order rather than coverage. On-disk provenance is shortened visibly and retained in accessible titles; exact captured timestamps reveal inline on hover/focus.

This pass changes neither capture/store protocols, native permissions, event schema, dependencies, nor the passive observation boundary. It does not certify human visual preference or untested physical/platform/native workloads. Reserved attachments, actual native multi-agent windows and further 3D/find animation remain explicit later additions, not silent omissions.
