# Independent agent and tool focus

13 October 2026. Functional continuation, before the builder's final visual-direction checkpoint. Uses installed `emil-design-eng` guidance: frequent focus changes are immediate, reversible and retain unrelated selection.

| Before | After | Why |
| --- | --- | --- |
| Selecting an agent erased the current tool/MCP focus | Agent selection changes only the owner dimension | Inspect one worker's selected kind of work |
| Selecting a tool erased the agent focus | Native kind or MCP server/tool preserves the selected owner | Narrow recorded activity without restarting navigation |
| Show all agents cleared every filter | Clears only agent focus; Clear focus still clears everything | Match the control's stated scope |

Classic, Studio and retained Legacy controls share the same helpers. Choosing an Inspector child explicitly sets that child and preserves action focus. Native kind and MCP server/tool are alternative action dimensions, combined with the agent by the existing deterministic composer. No capture/schema, policy or causal-link changes. The visible workspace-navigation entry accompanies review 67's keyboard picker.

The final UI/theme/animation pass is on hold pending builder clarification. Real-account native lifecycle and physical/platform release acceptance are still separate from synthetic transport and local functional checks.
