## Evidence and resource limits

Index only the complete text supplied to the component: valid object/array JSON within256 KiB, fewer than25000 values and80 levels. Parsing/indexing starts only on explicit inspection. Tree retains all accepted fields; a table is offered only for arrays of records (or `items`) with at most32 distinct columns. Wider data remains in Tree/Original. Missing is distinct from null. Search caps at500 matches with a visible caption; narrowing the query finds later values. Exact original text is never reconstructed by pretty-printing. Selected containers show type/count and can open their nested tree; scalar text is whole and selectable.

Invalid, truncated or over-limit trees keep the original supplied text. This is **not** full-artifact recovery and does not certify completeness of the harness's captured preview. CSV, image/resource/media transport and broader adaptive dispatch remain unchecked in TASKS. No requests to captured URLs, HTML execution, current-disk reads, dependencies, journal/schema changes or native turns.
