THE WORK IS THE INTERFACE

Three ways to see
what an agent actually did.

The same committed synthetic recording, three different spatial systems. Read the real excerpts, inspect a diff, open a failing assertion, follow a file and reveal the next captured passage. These are interactive design studies, separate from the integrated live reader.

One continuous account. Spacious source, compact outcomes, words on the world. Tools and file context keep their homes.

Recommended default: Studio.

One product, three task views: Studio follows the work, Relay compares agents, and Atlas explores the repository. Studio stays the default for combined chronology and code width. Production integration will share the session and preserve selection and reading position across views; these prototypes remain independent studies.
